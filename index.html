Your Torn key

HBountyTracker needs its own Public Only key. Make one in Torn's API key settings, pick Public Only, and name it HBountyTracker so you can spot it in your key log.

  • Your FFScouter key is optional. It goes in its own field and adds fair fight estimates.
  • Don't use your FFScouter key as the Torn key. It's a Custom key that can't read the bounty board, so it won't work.
  • Both keys stay in this browser and only ever go to Torn and FFScouter. The tool is open source, so you can read every line that touches them on GitHub.

How your key is used
Data storageOnly in your browser, on this device. Nothing is stored on a server.
Data sharingNobody. Your Torn key goes only to the Torn API. Your FFScouter key, if you add one, goes only to FFScouter, to fetch fair fight.
Purpose of useFinding bounty targets and showing their live status.
Key storage and sharingSaved in this browser's local storage only if you tick "Remember on this device". Never sent to The Great Stag. Disconnect wipes it.
Key access levelPublic Only.

Find targets

Rewards take 250k or 1.5m, and count per hit: one attack claims one bounty, the biggest on that target. Lower fair fight means an easier fight.

Pace and live checks

Torn allows 100 a minute across every tool and script you run. Leave room for the rest.

Okay targets get re-checked every 90 seconds. Anyone whose timer runs out gets checked again. Re-checks pause while this tab is in the background.

Sound plays for the same moments. The Sound button at the top turns all sound off.
